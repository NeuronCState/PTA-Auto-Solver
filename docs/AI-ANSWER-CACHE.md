# AI 解答缓存

- 使用脚本管理器 `GM_getValue/GM_setValue/GM_deleteValue` 本地持久存储，刷新、关闭页面后保留。不写入站点 localStorage，也不进入诊断/导出文件。
- 最多 200 条、约 2 MiB（按 UTF-16 字符估算），单条最多 128 KiB，7 天有效期，超限淘汰最久未使用项。仅保留最近使用账号的缓存包。
- 每轮作答或准备首次查询缓存前，通过当前题集正常 `/api/problem-sets/{id}/exams` 响应确认 `exam.userId` 和考试 ID。旧存储中的身份不能作为当前身份；身份未知、登录失败或接口异常时不读写缓存，继续正常调用模型。
- 缓存包按已验证账号隔离，键还包括站点/题集路由、题目 ID/位置、题型、完整提取数据（不含 DOM 引用）、语言、供应商/端点、模型、思考强度、Token 上限、图片设置。作答和辅助互不复用。
- 用户开启“跳过已答”并手动开始作答：本次运行不读取缓存，仍按原行为跳过已答题。其他作答运行及辅助准备可复用匹配缓存。
- 小题仅在现有格式校验、输入身份及用户编辑检查通过并成功写入后保存。缓存命中仍经过原有写入/统一保存检查；不会因缓存新增提交或跳转。
- 辅助仅缓存规范分段且选项映射无警告的结果。模型错误、空输出、格式不匹配不缓存。AI 内容的正确性并非可由格式验证保证。
- 编程题仅缓存 PTA 已明确满分的结果；重试不读缓存，非满分时移除对应缓存。
- “清除 AI 解答缓存”删除本地缓存并使当前页面正在请求的旧结果不能重新写回缓存。更换 API Key 也清除；Key 本身不进入缓存键或缓存包。不额外保存或传输 Cookie、Token、Key。

本地缓存包含题目数据和 AI 结果，属于用户授权的本地保存，不是加密保险库。没有进行真实供应商收费请求或真实 PTA 提交测试。测试包括新脚本实例模拟刷新、每次身份复核、多账号隔离、身份未知、TTL、清除及旧响应、损坏存储，以及同步/异步 GM API。

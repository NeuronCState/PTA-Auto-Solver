关于 PTA 自动刷题、
PTA 脚本与自动答题。

这是 PTA 自动刷题工具吗？

PTA Auto Solver 是在拼题 A 页面运行的 PTA 脚本，可把读题、调用 AI、填入编辑器与读取评分等重复步骤串成可见、可停止的流程。每次提交仍会留下 PTA 的真实记录。

如何安装 PTA 脚本？

先安装 Tampermonkey，再从本页导入 PTA Auto Solver。进入具体题目页后配置自己的 AI API Key，选择模型与语言即可使用。

PTA 自动答题如何保持可控？

脚本展示题目进度、运行记录和评分结果；首次使用建议关闭连续答题，核对生成的作答与评分后再决定是否继续。请遵守课程、竞赛和 PTA 的使用规则。

PTA自动答题常见问题
先看运行记录，再处理错误。

这里整理 PTA脚本使用过程中的常见问题。错误信息会显示在面板中，优先按照具体提示检查供应商、模型、题干和 PTA 页面状态。

为什么 API Key 错误不能获取模型？

请确认 Key 没有多余空格、供应商选项与 Key 来源一致、Base URL 正确且账户仍有额度。点击“获取模型列表”后，脚本会把错误显示在面板中。

为什么模型列表为空？

模型列表来自供应商的模型接口，不是脚本固定写死。检查网络连接、API Key 权限、供应商地址和接口是否兼容 OpenAI 风格模型列表。

MiMo 和 DeepSeek 的图片上传有什么区别？

MiMo 默认开启图片输入能力，DeepSeek 默认关闭。实际是否可用还取决于你选择的具体模型是否支持视觉输入。

为什么题干提取不完整或 AI 返回空内容？

先检查当前是否位于真实 PTA 题目页面，再查看运行记录中的“提取题干”内容。若模型只返回推理内容，可能需要提高 token 预算或换用支持结构化输出的模型。

为什么出现“响应不是有效 JSON”？

可能是模型没有按照提示词返回 JSON、模型的推理内容占满预算，或供应商对响应格式支持不一致。建议先提高 token 预算、换模型，并检查实际响应记录。

为什么没有自动进入下一题？

连续答题模式下，只有当前题得分达到满分才会点击下一题。未满分时脚本最多重新作答一次；第二次仍未满分时会停止，避免无限提交。

可以把 API Key 发布到 GitHub 吗？

不可以。API Key 只能填写在本地脚本配置中，不能提交到代码、截图、Issue 或 README。若 Key 已经泄露，请立即在供应商后台撤销并重新生成。

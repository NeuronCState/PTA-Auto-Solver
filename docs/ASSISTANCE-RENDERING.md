# 解析弹窗的本地排版

支持标题（`#` 至 `######`）、段落、粗体/斜体、行内代码、围栏代码块、有序/无序列表、引用、分隔线，以及行内/独立公式。其他 Markdown 扩展（例如表格、链接、图片）目前保留原文，不执行 HTML，不加载外部图片。

数学分隔符支持 `\(...\)`、`\[...\]`、`$...$`、`$$...$$`。模型返回双反斜线的 `\\(...\\)` / `\\[...\\]` 时，按双重转义处理公式中的命令；不会对普通代码全文盲目取消转义。整个响应是 JSON 字符串时，仅在可成功 JSON.parse 且结果为字符串时解一层。普通换行与代码内容保持不变。

KaTeX **0.16.22** 从官方 npm 包 vendored 到用户脚本，无运行时网络依赖。上游文件为 `katex@0.16.22/dist/katex.min.js`，SHA-256：`e8d885505949f3a5f4abdd5dd0d53696bd1371ad26ffbf4f310dcd77c8cdae89`。仅删除 sourceMappingURL 尾注，包在局部模块作用域内。许可证见 `KATEX-LICENSE.txt`。不污染页面全局 KaTeX，不使用页面上的第三方渲染器。

使用 `output: mathml`，依赖现代浏览器原生 MathML 排版，不需下载字体/CSS。设置 `trust:false`、`strict:error`、有限 maxExpand/maxSize；生成的结果还经 MathML 元素及属性白名单复制，排除链接、图片、事件、style 和 URL 属性。用户文本仅经 textContent / createTextNode 进入 DOM；不会把原始 Markdown 或模型 HTML 设置成 innerHTML。答案与公式不会发送给第三方渲染服务。

未知命令、非法公式、过长公式、渲染器不可用时保留原始公式为代码样式；提示“公式无法排版，显示原始 LaTeX”。超大响应（20 万字符以上）整段纯文本降级，避免昂贵解析。数学命令支持范围以 KaTeX 为准，不保证全部 LaTeX 宏包语法。

验证：`node tests/render-assistance.cjs` 为无外部测试依赖的回归，涵盖真实 KaTeX 解析、标题、列表、行内/块级公式、分数/下标、双转义、代码块保真、恶意 HTML/URL、额外白名单过滤及降级。另已使用临时安装的 jsdom 26.1.0 验证真实 DOMParser 路径，确认没有 script/img/a/iframe 或 URL/事件属性，也没有资源请求。尚未进行真实 PTA 浏览器视觉验收。

## 题号同排与小弹层

新界面将“查看解析”放到当前题号的同一排。实际诊断确认的小题结构为 `button[class*="label_"]` 所在 flex 行，大题为 `span.text-lg.font-bold` 所在 flex 行。只向确定的本题标题行追加自己的节点，不移动题号、分数或操作控件；无唯一可识别标题时保留本题内的安全回退位置，不猜测其他题号。

点击后显示按钮附近的非模态小弹层（宽度最多 440px、高度最多 560px），不再遮罩整个页面。随视口、滚动重新定位，锚点滚出视口/被移除时关闭。支持点外部关闭、Escape 关闭并恢复按钮焦点，Tab 可正常离开。淡入缩放动画遵循 `prefers-reduced-motion`。小题统一为“答案/解析”，大题为“解题思路/需要用到的方法”；仅当模型明确输出对应的两个标题时拆分，无明确分段时展示“模型原文”，不推断或捏造答案。

模型明确使用 `**粗体**` 标记的重点显示黄色荧光笔背景；不自动猜测哪些语句是正确结论。弹层注明荧光标记不代表已验证。已有 Markdown/公式安全边界保持不变。

新增 `tests/assistance-popover.cjs` 覆盖视口边界、规范分段与原文回退、题号定位及缺失/歧义回退；控制器测试覆盖外部关闭和 SPA 清理。另使用真实诊断 DOM 和 jsdom 验证 R2-1 小题 / R7-1 大题标题定位及移除题号后的回退，以及真实 DOM 非模态弹层、数学与高亮、Escape/外部关闭。没有真实 PTA 视觉验收。

## 固定选项格式与大题语句示例

选择/判断题的答案统一显示为“字母：原题选项内容”（如 `A：T`），多选每项一行。显示内容从该题已冻结的选项快照获取，不采用模型重写的选项内容。字母未知、重复标签、单选给多个字母、内容匹配歧义或明确不确定的回复不强行映射；保留原文并提示核对。模型字母有效但附带内容不一致时显示原题内容并明确警告。单独 T/F 只有唯一匹配原题选项时才转换为 A/B。原题选项通过 textContent 展示，HTML、Markdown、数学指令都不会在答案行被执行或重新解释；解析区域仍支持安全 Markdown/数学。填空题不套用选项格式。

大题第二段最新标题为“需要用到的语句”，请求多条关键语句/语法示例并逐项说明用途，不再只列一个方法名。允许互相独立的简短代码语句，仍禁止完整程序、完整函数、最终答案或可直接提交的实现。旧回复的“需要用到的方法”标题兼容映射成新标题。显式完整类/主函数/函数实现会被拒显；此检查是保守的启发式拦截，不能代替模型遵守内容约束。

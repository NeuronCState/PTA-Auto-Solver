PTA Auto Solver/安装教程

PTA SCRIPT GUIDE · 1.5.0

PTA自动答题脚本
安装与配置教程。

这是一份 PTA脚本安装指南，适用于想在拼题A页面使用 PTA Auto Solver 的用户。完成配置后，你可以读取题干、选择模型、生成作答建议并查看真实评分。

01

安装 Tampermonkey

使用 Chrome 或 Edge 打开浏览器扩展商店，安装 Tampermonkey。安装后确认浏览器右上角出现扩展图标。

PTA Auto Solver 是用户脚本，需要在 Tampermonkey 中运行。安装扩展后，点击页面上的 v1.5.0 脚本安装链接，确认导入并保存。

02

配置 AI 供应商与模型

进入 PTA 题目页面，在脚本面板中打开模型设置。当前支持 DeepSeek、MiMo 和 OpenRouter。

  1. 选择 AI 供应商并填写自己的 API Key。
  2. 点击获取模型列表，脚本会请求供应商返回可用模型。
  3. 从下拉列表选择具体模型；OpenRouter 的 Free 模型会优先显示。
  4. 根据模型能力决定是否开启图片输入。
安全提示

API Key 只保存在浏览器本地配置中。不要把 Key 截图、提交到 GitHub 或粘贴到公开讨论区。

03

选择编程语言并测试

编程语言选择位于首页，不需要进入供应商配置页面。支持自动识别题目类型，也可以手动选择 C、C++、Java、Python 等语言。

首次使用建议关闭连续答题，只测试当前题：核对脚本提取的题干、AI 生成的代码和编辑器内容，再点击提交本题作答。

04

提交、评分与下一题

提交后脚本会等待 PTA 程序评分，读取本题得分并判断是否满分。未满分时最多自动重新作答一次；选择连续答题且本题满分后，脚本才会进入下一题。

如果遇到题干为空、返回不是有效 JSON 或评分等待过久，请先查看面板运行记录和模型错误提示，再决定是否重试。

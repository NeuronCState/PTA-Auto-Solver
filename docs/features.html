PTA SCRIPT FEATURES · VERSION 1.5.0

PTA脚本功能说明
把重复操作变成可见流程。

PTA Auto Solver 是面向拼题A的 PTA自动答题脚本。它连接你自己的 AI API，读取当前题目，生成作答建议，并把提交和评分过程保留在页面中。

01

动态模型列表

填写 API Key 后向供应商请求真实模型列表，不固定模型名称。支持 DeepSeek、MiMo 和 OpenRouter；OpenRouter 的 Free 模型优先排列。

DEEPSEEK / MIMO / OPENROUTER
02

图片输入策略

MiMo 默认允许图片上传，DeepSeek 默认关闭图片上传。是否显示图片能力由供应商和模型配置决定。

IMAGE INPUT
03

题干提取

脚本从真实 PTA 页面提取题目内容，向 AI 提示词传递题干、输入输出要求和当前题型，减少手动复制。

QUESTION EXTRACTION
04

编程语言控制

首页直接显示编程语言选择框，支持自动识别与手动选择。下拉框采用脚本统一的黑白玻璃设计。

C / C++ / JAVA / PYTHON
05

评分闭环

点击提交本题后等待 PTA 打分，检测是否满分；未满分最多重答一次，并将每次生成和评分写入运行记录。

SUBMIT → SCORE → RETRY
06

连续答题

开启连续答题后，只有当前题满分才会进入下一题。进度按照实际题目总数计算，避免一直停留在“等待开始”。

PROGRESS / NEXT
WORKFLOW

一次答题的工作流

读取题干→请求 AI→写入编辑器→提交评分→满分后下一题
